## 优化手段与降幅

| 手段 | 做法 | 可量化指标 |
|---|---|---|
| 规则优先 | 判定 100% 走规则, 单次底稿判定环节 LLM=0 | 判定 LLM 调用数=0 |

| 结构化输出 | JSON mode, 避长文本重试 | JSON 一次成功率 |
