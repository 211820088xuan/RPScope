# 关联方识别系统的"假阳性"困境：为什么系统发现了年报没披露的关联方，不能简单当误报

> 这是 RPScope 项目 P5 评测阶段的核心洞察。一个"看起来 precision 只有 10.5%"的系统，为什么可能是有价值的。

## 问题的起点

我们做了一个 A 股上市公司关联方穿透系统：给定一家公司，自动产出它通过共同股东、共同实控人、董监高交叉形成的结构性关联方清单。规则引擎 R1-R7 全确定性（判定环节 LLM 调用数=0），跑在带时点的公司关系图谱上。

评测时，我们拿上市公司年报「关联方及关联交易」章节披露的关联方作金标准。结果（203 家，可比口径）：

- **precision 10.5%**，recall 2.1%（仅系统能力内的 upstream gold 子集）

10.5% 的 precision 意味着系统发现的候选里 89.5% 是"误报"——看起来系统没什么用。

但这里有一个被忽视的问题：**系统发现但年报未披露的候选，不全是误报。**

## 三分类：不是二元的对与错

年报金标准不是完美的标签。年报披露的是公司**自己认定并愿意披露**的关联方；系统发现但年报未披露的，实际上有三种情况：

1. **真漏报（true_omission）**——按上市规则确实构成关联人，但年报关联方章节未列示。这正是系统的价值：发现了公司未披露（可能疏漏，可能刻意隐瞒）的结构性关联。如果系统发现了一个同实控人下的兄弟公司而年报没列，这是系统发现了问题，不是系统出了问题。

2. **合理未披露（reasonable_undisclosed）**——关系客观存在但不满足披露的实质标准。比如虽有共同股东但持股比例很低、无实际影响；或者任职为独立董事（独董兼职普遍，关联认定另有口径）；或者关系已超出 12 个月窗口。这类候选系统找到的不是错，但年报不披露也不是错——两边都对，只是口径不同。

3. **系统误报（system_error）**——路径本身不成立。实控人识别错误、人名重名未消歧（"张伟"在两家公司各是不同人但被当成同一人）、通道类股东未排除干净、时点错配（用不同报告期的数据交叉）。这才是真正的 precision 杀手。

## 三分类框架的设计

三分类框架本身是评测方法论的核心贡献，而非某个具体结果。框架设计如下：

- **scope_class 分类**：将金标准条目按 `relation_desc` 关键词分为 upstream（系统能力内）/ downstream（能力外）/ other（无法判定）。203 家 7650 条中：upstream 2602 (34%)，downstream 1425 (19%)，other 3623 (47%)。可比口径仅取 upstream 子集作分母，排除系统覆盖不到的部分。
- **三组口径**：严格（全量 gold）/ 可比（仅 upstream）/ 能力外（仅 downstream），三组都报 P/R/F1。
- **system_only 核查**：系统发现但年报未披露的候选（可比口径 458 条），需人工逐条判定属于上述三类中的哪一类。**人工三分类尚未进行**，因此 precision 未做修正——这是一个已知缺口而非已完成的工作。
- **修正后 precision 的计算方法**（待人工核查后执行）：把 `true_omission` 计入 TP（系统发现年报未披露的实质关联 = 系统价值 = 应算命中），`reasonable_undisclosed` 和 `system_error` 仍算 FP。修正后 P = (matched + true_omission) / (matched + system_only)。

## 为什么这很重要

**如果只看原始 precision 10.5% 就否掉这个系统，你会错过一个能发现真实漏报的工具。**

关联方隐瞒是 A 股财务造假的高频手法（康美药业、康得新、乐视网，证监会的处罚决定书里关联方隐瞒都是关键）。一个能自动发现"年报没列但按规则应该列的关联方"的系统，它的价值不在 precision 的高低，而在于它发现了什么。

三分类的核心洞察：**评测不应该只问"系统说的对不对"，还应该问"系统说了年报没说的，这些到底是漏报还是误报。"** 把这三个分开统计，比一个笼统的 precision 数字有意义得多。

## 技术细节

- 系统判定 100% 确定性（规则引擎 R1-R7，LLM 调用数=0），所以"系统说的"是可回溯的事实，不是概率生成
- 年报金标准含 47% 的 other（relation_desc 为空无法判定上下游），可比口径仅取系统能力内的 upstream 子集（2602 条）
- 政府控制人排除修复后，R2 候选从 169 降至 16（-90.5%），其中深圳市国有资产监督管理局（局≠委员会，正则漏排）贡献了 1458 条假阳性
- 人工三分类尚未进行，模型标注文件已全部删除（不构成人工基准）
