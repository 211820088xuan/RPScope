## T4: 修复

### D类修复 1: 序数通配
`coreference.py` `_extract_ordinal` 增加中文数字通配(第一~第十)和阿拉伯数字(第N个), 不再仅依赖配置表中的固定词。

### D类修复 2: 代词歧义防护
`coreference.py` 代词指代分支增加检查: 焦点栈有 ≥2 个 user_mention 实体时返回澄清, 不解到栈顶。

### D类未修复(词典缺口)
"茅台"注册名为"贵州茅台", 词典无法匹配。这是数据层面的问题, 不应在代码中硬编码别名。正确做法是在 company 表增加 alias 字段或通过 LLM 兜底处理(当前已走 LLM 兜底路径)。

### A类: 仅改测试断言, 不动系统
- name_fragment: "宁德时代那个呢" 含显式实体, 系统走正常抽取是正确行为
- pronoun_ambiguous: 测试模拟的 record_turn 只存 1 个实体, 无歧义
