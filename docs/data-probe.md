## 三、初始阈值校准（config/rules.yaml）

基于真实分布，给出初始阈值及理由：

- **R1/R3 min_ratio = 5%**：维持。对应交易所关联人认定线，且十大股东天然截止在~5%附近。
- **R3 require_same_period = true**：维持。跨期混算会导致假共同股东。
- **R4 title_classes 不含独立董事**：维持。独董兼职普遍，会污染连锁董事结果。
- **R6 max_hops = 3**：3跳连通度数据显示可达公司数显著增长，但>3跳语义稀薄且易超时，限3。
- **通道排除名单**：当前 exact+patterns 已把香港中央结算/证金/汇金/ETF/社保组合/资管计划排掉，排除后最高度数 74。名单够用。

## 四、对项目可行性的影响（Go/No-Go）

### 各规则数据源的真实强度

| 规则 | 数据强度 | 说明 |
|---|---|---|
| R1 直接持股 | 强 | 批量55603行，个股含`占总股本持股比例` |
| **R2 同一控制** | **强（核心）** | 实控人覆盖 5577 家，R2 成为首要边来源 |
| R3 共同股东 | **弱（近乎失效）** | 50样本仅 4/1225（0.3%）对有非通道共同股东；加 ≥5% 过滤后更少 |
| R4 连锁董事 | **强（核心）** | 高管覆盖 5082 家，1864 人在≥2家任职 → 消歧工作量 |
| R5 关键人 | 中 | 复用 R4 的人+R1 的持股 |
| R6 股权穿透 | 中 | 依赖 R1 链；2跳可达 2248，3跳 3942 |
| R7 担保 | 强 | 3032 家对外担保，官方结构化 |

### 共同股东稀疏的根因（诚实分析）

- A 股十大股东中，~28% 是通道（ETF/社保/QFII/资管），排除后真实持有人本就稀疏。
- 剩余非通道股东里，能同时出现在两家公司十大且各达 5% 的极少（0.3% 对）。
- 这不是数据缺失，而是**市场结构事实**：A 股的关联性主要由实控人(同一控制)和董监高交叉承载，而非分散的共同股东。
- 业务准则第36号第六条第(二)项也印证：单纯持股重叠不必然构成关联方。

### 方案调整（铁律1：改方案，不要硬做）

原计划把 R2 与 R3 并列为⭐核心。真实数据显示 **R3 近乎失效**，必须调整：

1. **R2 同一控制 升为首要规则**：实控人是官方披露的强信号，覆盖5577家，是图的主要边来源。
2. **R4 连锁董事 升为并列首要**：5082家高管覆盖、1864人跨公司任职，配合 P2 消歧后是第二边来源。
3. **R3 共同股东 降级**：保留规则但标 `low` 置信，仅作上下文，不进主结论集；阈值卡 ≥5% 严格不动。
4. **R6 股权穿透** 路径来源改为以 R1+R2 链为主（R3 链已稀疏）。

### 结论：**GO（条件：上述 R3 降级调整生效）**

- ✅ R1/R2/R4/R5/R7 数据源全部到位且强度足够支撑多跳查询。

- ✅ R2 实控人 + R4 连锁董事 作为双核心，足以构成有意义的关联图谱。
