# RPScope — A 股上市公司关联方穿透与风险底稿系统

> 给定一家 A 股上市公司，自动产出一份**关联方与风险底稿**：谁是它的关联方、通过什么路径关联、依据哪条规则与哪份数据、这些关联方最近发生了什么风险事件。每条结论带路径+来源+时点+置信度，可人工复核。

## 业务问题

年报只披露公司**自己认定并愿意披露**的关联方；而通过共同股东、共同实控人、董监高交叉形成的结构性关联，人工要跨公司比对才能发现，全市场几千家做不过来。RPScope 把交易所上市规则的关联人认定标准工程化为图查询规则，跑在带时点的公司关系图谱上。

## 架构

```
接入层  CLI / FastAPI / 单页前端(vis-network)
编排层  LangGraph Agent(意图路由→取种子→规则查询→事件挂载→断言回查→撰写)
规则层  R1-R7 【无 LLM】            检索层  图遍历/BM25/RRF
存储层  SQLite 事实源(可重建) + networkx 图计算视图(PG/Neo4j 可换)
数据层  akshare(持股/任职/实控人/担保/诉讼/质押) + 巨潮年报(金标准)
```

**核心架构主张**：关联方判定的输出是有法律含义的事实断言，必须可回溯到具体数据行，不能来自概率生成——所以**大模型完全挡在判定逻辑之外**（判定环节 LLM 调用数=0，零幻觉空间）。LLM 仅用于实体消歧兜底、公告事件抽取、报告撰写，且输出经断言级回查。

## 核心指标

| 指标 | 数值 | 来源 |
|---|---|---|

| 关联方识别 precision / recall（对照年报金标准） | 可比口径 6.2% / 2.5%（upstream 子集）；严格口径 8.4% / 1.3% 对照 | P5 |
| 人名消歧准确率 | 93.3%（独立模型银标，调优后） | P2 |
| **判定环节 LLM 调用数** | **0** | 铁律2 |
| 断言回查通过率 | 100%（基线，幻觉 0%） | P8 |
| 单次底稿耗时 / token / 成本 | 秒级 / 214+10697 tok / ≈0.011 元 | P10 |
| 三分类（matched/系统发现待核查/年报未验证） | 19 / 208 / 1439（28家） | P5 |

> recall 1.3% 是结构性的非缺陷：年报金标准含大量下游（子公司/联营），系统基于公开接口只覆盖上游（股东/董监高/实控人），下游属"合理未披露"。precision 偏严：208 条"系统发现未披露"全算 FP，但其中"真漏报"按准则是关联方（如兄弟公司），是系统价值而非误报——须人工三分类后修正。

## 7 条关联方判定规则（R1-R7，无 LLM）

- **R1 直接持股**：股东≥5%/20%/50% → high
- **R2 同一控制** ⭐：共同实控人 → 兄弟公司（准则"同受国家控制不构成关联方"，政府控制人排除）
- **R3 共同股东**：同股东两边≥5% 同期 → low（P0 实测近失效，A 股关联性由实控人/董监高承载，非分散共同股东）
- **R4 连锁董事** ⭐：同一自然人任两公司董监高 → 置信≤消歧置信
- **R5 关键人**：董监高同时是别家重要股东
- **R6 间接穿透**：1-3 跳股权链比例乘积
- **R7 事件型**：担保/质押等（成对担保需 P6 文本抽取）

## 快速开始

```bash
pip install -e ".[dev]"
# 数据探针 + 入库（首次，全市场，需 akshare 联网）
py scripts/probe.py && py scripts/analyze_probe.py
py -m src.data.ingest
py scripts/rebuild_graph.py
py scripts/run_rules.py 200          # 规则引擎批量跑
py scripts/make_report.py 002594     # 产出底稿 JSON+HTML
py -m uvicorn src.serve.main:app --port 8765   # API + 前端
```

起服务后浏览器打开 **http://127.0.0.1:8765**：输入股票代码生成底稿 + 关联路径图(vis-network) + 问答框(接 `/api/ask`)。

`cp .env.example .env` 填 `GLM_API_KEY`（经 DashScope 兼容端点）后启用消歧兜底/事件抽取/报告撰写。`RPSCOPE_LLM_ENABLED=false` 时全系统走降级路径（规则+模板）仍可产出底稿。

## 诚实声明边界（加分项）

- ❌ 不做投资建议/评级/价值判断
- ❌ 不做深度工商穿透（无工商数据源，公开接口只到十大股东）
- ❌ 不做协议型一致行动人识别（依赖协议披露，数据不可得）
- 图谱上行（股东/董监高/实控人）完整，下行（子公司/联营）残缺——公开数据天花板
