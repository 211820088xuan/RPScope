# RPScope — A 股上市公司关联方穿透与风险底稿系统

## 这是什么

给定一家 A 股上市公司，自动产出一份关联方与风险底稿：谁是它的关联方、通过什么路径关联、依据哪条规则与哪份数据、这些关联方最近发生了什么风险事件。每条结论带路径 + 来源 + 时点 + 置信度，可人工复核。

## 解决什么问题

年报只披露公司自己认定并愿意披露的关联方；而通过共同股东、共同实控人、董监高交叉形成的结构性关联，人工要跨公司比对才能发现，全市场几千家做不过来。RPScope 把交易所上市规则的关联人认定标准工程化为图查询规则，跑在带时点的公司关系图谱上，重点是找出年报没列、但按规则应该列的关联方。

## 架构

```
接入层  CLI / FastAPI / 单页前端(vis-network)
编排层  LangGraph Agent(意图路由→取种子→规则查询→事件挂载→断言回查→撰写)
规则层  R1-R7（无 LLM）        检索层  图遍历 / BM25 / RRF
存储层  SQLite（事实源，可重建）+ networkx（图计算视图）
数据层  akshare（持股/任职/实控人/担保/诉讼/质押）+ 巨潮年报（金标准）
```

关联方判定的输出是有法律含义的事实断言，必须可回溯到具体数据行，不能来自概率生成——所以判定环节不调用 LLM（调用数 = 0）。LLM 仅用于实体消歧兜底、公告事件抽取、报告撰写，且输出经断言级回查。

## 7 条关联方判定规则

| 规则 | 说明 | 置信度 |
|---|---|---|
| R1 直接持股 | 股东 ≥5%/20%/50% | high |
| R2 同一控制 | 共同实控人 → 兄弟公司（政府控制人排除） | high |
| R3 共同股东 | 同股东两边 ≥5% 同期（实测近失效） | low |
| R4 连锁董事 | 同一自然人任两公司董监高 | ≤消歧置信 |
| R5 关键人 | 董监高同时是别家重要股东 | high |
| R6 间接穿透 | 1-3 跳股权链比例乘积 ≥5% | high |
| R7 事件型 | 担保 / 质押等 | high |

通道类股东（ETF、社保、QFII、政府监管机构等）在入图前排除，名单见 `config/rules.yaml`。

## 核心指标

| 指标 | 数值 |
|---|---|
| 覆盖公司 / 实体 / 关系边 | 5927 / 61225 / 196415 |
| 关联方识别 P / R（可比口径） | 10.5% / 2.1%（upstream, 203 家, 7650 条） |
| 关联方识别 P / R（严格口径） | 19.5% / 1.5% |
| 判定环节 LLM 调用数 | 0 |
| 断言回查 | 反转检测(提取疑似实体→不在DB即可疑) + 评价性/因果/投资倾向检查；真拦截率 47%，覆盖虚构公司名/代码/张冠李戴；已知缺口：数值篡改、日期篡改不拦 |
| 单次底稿耗时 / 成本 | 秒级 / ≈0.011 元 |
| 2 跳查询 P95 | 0.15ms |

口径说明：覆盖公司 = akshare 全表（A 股 + B 股）经去重后的 6 位代码公司数。实体 = 非通道 entity 数。关系边 = 图中不同（实体, 公司）对的边数。

## 项目结构

```
src/
  store/        SQLite 事实源 + networkx 图计算视图
  normalize/    名称规范化
  data/         akshare 数据探针与入库
  graph/        图构建与查询
  disambiguate/ 人名消歧（5 信号 + LLM 兜底）
  rules/        R1-R7 规则引擎
  gold/         年报金标准构建（pymupdf 定位 + 抽取）
  extract/      事件抽取
  agent/        LangGraph 意图路由 + 断言回查
  report/       底稿生成（JSON / HTML / PDF）
  serve/        FastAPI + 缓存 + 可观测性
  eval/         对齐器 + 三口径指标
config/         rules.yaml（阈值 + 通道排除名单）
scripts/        数据探针 / 图构建 / 规则批量跑 / 报告生成 / 评测
docs/           设计文档 + 评测报告 + 进度日志
web/            单页前端（vis-network 关联图）
```

## 快速开始

### 1. 安装

```bash
pip install -e ".[dev]"
```

### 2. 配置

```bash
cp .env.example .env
```

编辑 `.env`，填入 `GLM_API_KEY`（经 DashScope 兼容端点）。该项用于消歧兜底 / 事件抽取 / 报告撰写；不填或设 `RPSCOPE_LLM_ENABLED=false` 时走降级路径（规则 + 模板），仍可产出底稿。

### 3. 数据入库（首次，需联网）

```bash
py scripts/probe.py            # 数据探针，验证 akshare 接口可用性
py -m src.data.ingest          # 全市场入库（持股/任职/实控人/事件）
py scripts/rebuild_graph.py    # 构建 networkx 图
```

### 4. 跑规则引擎

```bash
py scripts/run_rules.py 200    # 批量跑 200 家公司
```

### 5. 生成底稿

```bash
py scripts/make_report.py 002594    # 产出 JSON + HTML 底稿
```

### 6. 起服务

```bash
py -m uvicorn src.serve.main:app --port 8765
```

浏览器打开 http://127.0.0.1:8765 ：输入股票代码生成底稿，查看关联路径图，使用问答框。

## 边界

- 不做投资建议 / 评级 / 价值判断
- 不做深度工商穿透（无工商数据源，公开接口只到十大股东）
- 不做协议型一致行动人识别（依赖协议披露，数据不可得）
- 图谱上行（股东 / 董监高 / 实控人）完整，下行（子公司 / 联营）残缺——公开数据天花板
